# ASL image assets

Images live under `fingerspell/` (A–Z) and `words/` (dictionary glosses).

## Regenerating

From the repo root:

```bash
node scripts/fetch-asl-assets.mjs
```

The script tries [Wikimedia Commons](https://commons.wikimedia.org/) files where a known title exists, then writes SVG placeholders for anything missing.

## License notes

When Commons downloads succeed, those files remain under the license shown on each file’s Commons page (often CC BY-SA). Placeholder SVGs generated by this repo are part of the project and may be replaced with licensed reference photos over time.

## Fingerspelling (Commons targets)

- `American_Sign_Language_ASL_alphabet_*.svg` (letters A–Z)

## Word signs (Commons targets when available)

- hello, thank you, please, yes, no, help, love, water, home, school — see `WORD_COMMONS` in `scripts/fetch-asl-assets.mjs`

Other dictionary words use generated placeholders until you add real reference images with matching `{imageId}.svg` filenames.
